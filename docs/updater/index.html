  1. connect the pedal to this computer via usb
  2. power the pedal
  3. hold both footswitches for 2 seconds — the leds alternate, then the pedal waits in dfu mode

since v0.5 the pedal needs the electro-smith daisy bootloader installed (one-time setup — NitroTron3 pedals shipped/updated after 2026-07-21 already have it). without it this tool cannot flash. install it once via the daisy web programmer ("flash bootloader image") from the BOOT/RESET-button dfu mode — see the release page's INSTALL.md for the step-by-step. firmware older than v0.5 is not offered here anymore.
